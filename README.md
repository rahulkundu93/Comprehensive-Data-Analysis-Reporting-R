# Week 4 – Comprehensive Data Analysis Reporting and Presentation

This repository consolidates the four-week Titanic data analytics internship project completed using R.

## Project modules
- Week 1: Data cleaning and preliminary analysis
- Week 2: Data visualization and insight communication
- Week 3: Statistical hypothesis testing and logistic regression prediction
- Week 4: Integrated final report

## Dataset
Titanic passenger dataset (891 records). Target variable: survival status. Predictors include passenger class, sex, age, family counts, fare, and embarkation point.

## Key reference model results
- Accuracy: 80.45%
- Precision: 79.31%
- Recall: 66.67%
- F1-score: 72.44%
- Test ROC-AUC: 84.32%
- Mean 5-fold CV ROC-AUC: 85.28%
